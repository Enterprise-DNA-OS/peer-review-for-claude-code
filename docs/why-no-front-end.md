# Why this desk has no application front end

The editorial office asks questions, records decisions and prepares documents through its coding agent. The database is the product. Read-only branded HTML gives the meeting a stable snapshot. There is no application server or interactive portal.

A submission screen gives authors upload controls and a reviewer portal gives reviewers private access. Mobile notifications, offline work, live co-editing, document annotation and drag-and-drop assignment need other software. This package supplies none of them. Keep your approved document store and communication process while running the editorial desk. Enterprise DNA can scope portals and connections for your version. This base never sends, publishes papers or collects fees.
