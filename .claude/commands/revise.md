# /revise

Preserve the earlier round. Only a recorded revision decision permits a new round.

Run with the operator's actual identifiers and values:

```bash
npm run peer -- revise --ref=M-104 --file-ref="vault:revised-file" --due-on=2027-01-15 --actor="Your name"
```

Use --json for machine output. Examples are fictional, not authorization to change real records.
